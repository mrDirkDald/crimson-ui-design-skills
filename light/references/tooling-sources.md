# Tooling Sources and Freshness

Tool names and capabilities can change. Verify current upstream documentation before installing or relying on version-sensitive flags.

Optional tools referenced by this skill include:
- fchek — broad developer/AI toolbox;
- skill-check — Agent Skill validation;
- npm-safe — npm package safety scanning;
- Playwright — browser/Electron renderer automation;
- axe-core or equivalent accessibility automation;
- Lighthouse or equivalent browser performance tooling;
- Storybook or equivalent component-state harnesses.

The skill does not authorize automatic installation of any external tool.
