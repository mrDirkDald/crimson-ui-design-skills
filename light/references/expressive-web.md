## Activation gate

Load this reference only when the browser surface materially benefits from expressive direction, for example:
- portfolio / creative studio;
- campaign / promotional site;
- festival / event;
- cultural / editorial experience;
- entertainment / music / film;
- luxury / architecture / visual-brand site;
- experimental interactive story;
- explicit request for award-level / Awwwards-like direction.

Do **not** load it by default for:
- admin panels;
- internal tools;
- conventional SaaS workspaces;
- dashboards;
- forms-heavy utilities;
- repeated operational workflows.

An expressive brief changes the design budget, not the usability standard.

## Award-site bias guard

Award galleries over-represent sites whose job is to impress, narrate, promote or demonstrate craft.

Do not transplant spectacle into a product whose real job is repeated task completion.

Before using an award-style pattern ask:

```text
PRODUCT JOB:
FREQUENCY OF USE:
VALUE OF DELIGHT / BRAND EXPRESSION:
COST OF SPECTACLE:
CONVENTIONAL FALLBACK NEEDED:
```

A pattern is valid only when its communication/brand value justifies its cognitive, performance and implementation cost.

“Award-worthy” is not automatically “product-appropriate”.

## Cross-source reference gate

When references materially shape the direction, also use `web-reference-corpus.md`. Award galleries are evidence for spectacle/art direction, not universal evidence for repeated-task UX. Triangulate with product-flow, typography or implementation references when those decisions matter.

Do not confuse a frequently awarded motif with a product-specific idea. If the reference set contains the same visual niche repeatedly, apply a saturation penalty and search for the underlying mechanism rather than copying the motif.

## One-thesis rule

Strong expressive sites usually benefit from one dominant identity move rather than many unrelated tricks.

Examples of dominant moves:
- one hero object;
- one continuous illustrated world;
- one unusual typographic system;
- one content metaphor;
- one spatial interaction;
- one narrative scroll device;
- one distinctive work-gallery behavior.

Supporting UI should recede enough for the thesis to remain legible.

If the site needs a list of five effects to explain why it is distinctive, the direction is probably unfocused.

Write:

```text
EXPERIENCE THESIS:
DOMINANT MOVE:
SUPPORTING MOTION:
WHAT MUST STAY QUIET:
```

## Subject-to-experience mapping

Derive the expressive device from the actual subject.

Good mapping:
- architecture → scale, material, plans, spatial sequencing;
- festival → lineup, stages, timetable, campaign art, crowd energy;
- cinema → screening rhythm, curation, posters, showtimes, physical theatre atmosphere;
- product studio → shipped work, proof, process, system thinking;
- craft/food/luxury → material, process, provenance, product detail;
- creative tech → interaction itself can demonstrate capability.

Weak mapping:
- unrelated floating 3D blob;
- generic gradient mesh;
- random particles;
- cinematic preloader with no subject relationship;
- identical pinned-scroll template used regardless of product.

Identity should come from the product’s content, workflow, material or story before it comes from effects.

## Work-led portfolios and agencies

When the work itself proves capability, let it carry the page.

Pattern:

```text
short positioning
→ strong selected work
→ enough context to understand scope/result
→ studio/process proof
→ contact / next action
```

Prefer showing real work over paragraphs claiming creativity.

For case studies, preserve:
- project identity;
- problem/context;
- role/scope;
- visual result;
- useful outcome/proof when available.

Do not bury portfolio work under a giant generic manifesto.

Do not manufacture fake conversion metrics or client proof.

## Event / festival mode split

Event sites often have two different product modes.

### Before the event
Prioritize:
- identity / atmosphere;
- dates/location;
- tickets;
- lineup discovery;
- practical information;
- anticipation.

### During the event
Prioritize:
- timetable;
- current/next acts;
- stage/location;
- fast mobile navigation;
- saved/favorite acts when supported;
- updates / critical notices.

The high-expression campaign layer must not make the in-event utility slower to use.

Responsive/mobile behavior may need a different hierarchy rather than a smaller desktop campaign.

## Interactive product-as-proof

If the product contains a compelling core interaction, consider letting visitors experience it rather than explaining it with decoration.

Examples:
- customize a product;
- run a real grader/tool;
- explore a dataset;
- try a constrained editor;
- manipulate a meaningful object;
- preview a real workflow.

The interaction should be:
- real enough to prove value;
- clearly bounded;
- recoverable;
- performant;
- accessible through a conventional path where necessary.

Do not build an expensive toy unrelated to the product’s actual value.

## Scroll narrative and pacing

Scroll can be a narrative input when progression actually changes understanding.

A scroll-driven moment should do at least one:
- reveal consequential information;
- transform the scene in a meaningful way;
- connect cause/effect;
- move through a spatial/story model;
- stage content with deliberate pacing.

Do not animate an element merely because it entered the viewport.

### Pacing rhythm

Mix dense and sparse sections intentionally.

Avoid:
- every section being full-screen and monumental;
- every section using the same reveal;
- constant animation with no resting state;
- long dead-scroll regions.

The user should periodically return to a stable reading/decision state.

## Motion choreography

Classify motion before implementing it.

### Functional motion
Communicates state, hierarchy, causality, progress or spatial continuity.

### Narrative motion
Advances the story or product metaphor.

### Brand motion
Creates a recognizable interaction signature.

### Decorative motion
Adds atmosphere only.

Priority:
`functional → narrative → brand → decorative`

Use fewer high-value sequences instead of animating everything.

Motion choreography should share:
- timing character;
- easing language;
- direction/spatial logic;
- intensity.

Do not stack unrelated animation styles on the same surface.

Respect reduced motion with an equivalent readable path.

## Immersive 3D / WebGL

Use 3D/WebGL when spatial/visual behavior materially supports the subject or identity.

Before adding it define:

```text
WHY 3D:
USER VALUE:
FIRST MEANINGFUL CONTENT WITHOUT IT:
LOADING STATE:
LOW-POWER / MOBILE FALLBACK:
REDUCED-MOTION PATH:
FAILURE FALLBACK:
```

Core information/navigation must not disappear because a renderer fails.

Do not block the whole site behind a long preloader for a decorative scene.

Use one strong 3D thesis before multiple unrelated WebGL effects.

## Typography as composition

Expressive display typography may create spatial structure.

It may use:
- unusual scale;
- deliberate crop;
- tension with imagery;
- strong contrast in width/weight;
- editorial alignment shifts.

But preserve:
- readable navigation;
- readable body copy;
- meaningful heading hierarchy;
- scanability;
- localization resilience.

Do not use extreme tracking, stretched type or tiny metadata everywhere merely to signal “design”.

Typography can replace unnecessary cards/borders by providing hierarchy directly.

## Asymmetry and editorial tension

Asymmetry is useful when it creates hierarchy, movement or subject-specific character.

Use deliberate:
- offset columns;
- image/text imbalance;
- controlled overlap;
- variable section widths;
- crop and negative space.

The composition still needs alignment anchors.

Random misalignment is not editorial design.

At narrow widths, recompute the hierarchy rather than preserving desktop tension mechanically.

## Media art direction

For photography/video/illustration define:
- focal subject;
- crop/safe zones;
- aspect behavior;
- visual temperature;
- repetition rules;
- captions/context when needed;
- fallback/missing state.

Large media should carry information, atmosphere or identity.

Do not use full-bleed imagery merely because award sites often do.

### Video

Video should have:
- poster/fallback;
- loading behavior;
- mobile/data consideration;
- no dependence on autoplay audio;
- readable foreground contrast.

## Color focal allocation

Color can be concentrated instead of evenly distributed.

A valid expressive pattern is:

```text
quiet base
→ one chromatic artwork/object/content focus
→ restrained controls
```

This often creates stronger identity than coloring every button/heading.

Map where chroma is allowed:
- hero/artwork;
- interaction accent;
- semantic states;
- selected/highlight state.

Do not let decorative chroma compete with the primary visual thesis.

Core color-harmony and accessibility rules still apply.

## Experimental navigation

Unusual navigation must still answer:
- where am I?
- what can I visit?
- how do I return?
- what happens on Back/reload/deep link?

If navigation is spatial/canvas-based, provide an understandable conventional fallback or equivalent index when needed.

Keyboard, touch and small-screen users must retain access to the core route structure.

Do not hide fundamental navigation solely to create mystery.

## Page transitions

Use route/page transitions when they preserve continuity or reinforce the thesis.

Requirements:
- no interaction dead time longer than the experience value justifies;
- history/back remains correct;
- content appears even if transition fails;
- reduced-motion path;
- loading is not disguised as arbitrary theatre.

Not every route needs a transition.

## Sound

Sound is optional and high-cost.

If used:
- default to muted/no unexpected audible autoplay;
- provide visible control;
- remember preference when appropriate;
- do not make core understanding depend on audio;
- provide text/visual equivalent for meaningful audio cues.

Use sound only when it contributes materially to atmosphere, interaction or subject.

## Footer as brand scene

A footer may carry one final brand moment after the functional content is complete.

It may be more expressive than routine navigation.

Still preserve:
- legal/privacy links;
- contact route;
- required navigation;
- readable controls.

Do not make users hunt through an animation for essential footer content.

## Responsive recomposition

An expressive desktop composition usually cannot be solved by proportional shrinking.

At each major width decide what happens to:
- visual thesis;
- media focal point;
- overlap/asymmetry;
- typography scale;
- navigation;
- motion intensity;
- 3D/canvas detail;
- practical CTA.

Preserve the **idea**, not every desktop coordinate.

Mobile can use a simpler expression of the same thesis.

## Performance / experience budget

Every spectacle feature spends budget in:
- JS/runtime cost;
- GPU cost;
- media bytes;
- startup delay;
- input latency;
- battery/data;
- accessibility complexity;
- implementation/maintenance cost.

Before a high-cost effect, define what it buys.

Prefer progressive enhancement:
- meaningful HTML/content first;
- enhanced motion/media second;
- heavy immersive layer last.

If an effect compromises core interaction performance, simplify or remove it.

## Accessibility and fallback

Experimental presentation does not reduce accessibility obligations.

For canvas/WebGL/custom scroll/cursor/drag:
- keep semantic content available;
- preserve keyboard route/navigation;
- support standard scrolling or equivalent access;
- avoid pointer-only essential interactions;
- support reduced motion;
- maintain visible focus;
- provide meaningful fallback when rendering fails.

Custom cursor may supplement, never replace, the real pointer/focus model.

## Trend saturation penalty

Frequently-seen award patterns are not forbidden, but they need stronger product justification.

Common saturated devices include:
- oversized grotesk hero type;
- pinned scroll sequence;
- floating 3D object;
- infinite image gallery;
- custom cursor;
- dramatic preloader;
- full-bleed video;
- horizontal-scroll portfolio;
- page wipe transition.

If the pattern could be copied unchanged into unrelated sites, either:
1. derive it more deeply from the subject;
2. combine it with a product-specific interaction/content model;
3. choose a less saturated device.

Do not copy an Awwwards composition just because it is award-recognized.

## Reference synthesis

When studying multiple expressive references, do not copy whole layouts.

Use a synthesis table:

```text
REFERENCE:
PATTERN:
WHY IT WORKS:
WHERE IT WOULD FAIL:
PRODUCT FIT:
TRANSFERABLE PRINCIPLE:
ADAPTATION:
```

Then cluster repeated principles across references.

Prefer principles supported by several different sites over one-off fashion.

Use the reference board to identify:
- common high-value patterns;
- oversaturated trends;
- domain-specific moves;
- interaction/performance tradeoffs.

## Attention and continuous-motion budget

Expressive motion spends attention.

Treat these as competing attention sources:
- auto-advancing hero reel;
- infinite CTA pulse;
- marquee/ticker;
- animated counters;
- parallax;
- blinking/live indicators;
- card hover transforms;
- scroll reveals;
- audio visualization.

A page may use several, but not all should demand equal attention at the same moment.

Define:

```text
DOMINANT ACTIVE MOTION:
SUPPORTING MOTION:
CONTINUOUS MOTION THAT CAN BE REMOVED:
REDUCED-MOTION RESULT:
```

Prefer one dominant active motion per viewport and quieter supporting motion.

### Auto-media state contract

For reels/video/audio with autonomous behavior:
- show state when the sequence matters;
- expose progress/chapter when useful;
- provide pause/mute/manual navigation where appropriate;
- stop or reduce motion under reduced-motion preferences;
- preserve content if the media layer fails.

### Input-equivalent reveals

Hover-only reveal is not sufficient for essential information.
Provide equivalent tap/click and keyboard paths, plus visible affordance and semantics.
