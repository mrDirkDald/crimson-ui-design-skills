# Content and Microcopy

## Action labels

Use verbs that describe outcome: Download, Save changes, Copy address, Retry, Open folder. Avoid generic “Continue” when a more specific outcome is known.

## Error messages

State what happened, what the user can do, and whether data was preserved. Do not blame the user.

## Empty states

Explain why the area is empty and provide the next meaningful action when one exists. Do not fill every empty state with illustration and marketing copy.

## Metadata

Show technical detail when it helps decision-making, debugging, or confidence. Demote detail that is rarely needed instead of removing it blindly.
