# Images and Media

## Purpose

Every major image should have a role: product evidence, subject identity, emotional tone, navigation, education, or decoration.

## Crop

Define object-position/focal-point behavior across aspect ratios. The same crop rarely works perfectly from ultrawide desktop to portrait mobile.

## Text over image

Use local overlays, scrims, gradients, blur, or repositioning according to the content rather than one global opacity.

## Galleries

Preserve aspect ratio, keyboard navigation, touch gestures, loading states, captions/alt text, and clear selected state.
