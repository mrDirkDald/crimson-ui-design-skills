# Data Visualization

## Start with the question

Do not choose a chart because it looks impressive. Define what comparison or decision the user needs.

## Encodings

Position and length are generally easier to compare accurately than area, angle, or color. Use color to support structure, not replace it.

## Categorical colors

Use stable category meaning. For many series, direct labels, interaction, grouping, small multiples, markers, or line styles often work better than more colors.

## Sequential

Use monotonic lightness/chroma for magnitude.

## Diverging

Use only with a meaningful center.

## Accessibility

Do not make red/green the only difference. Provide labels, symbols, patterns, or positional distinction where critical.
