# Crimson UI Design — Tests

This package contains the benchmark/evaluation corpus for Crimson UI Design.

It is deliberately separated from the runtime skill so ordinary UI work does not spend context/tokens scanning fixtures, screenshots, benchmark specs, scoring artifacts, or evaluation scripts.

Use this package only when:
- evaluating the skill itself;
- validating benchmark fixtures;
- comparing baseline vs candidate behavior;
- changing benchmark/evaluation infrastructure.

Do not install or load this package for ordinary design, implementation, or QA tasks.
