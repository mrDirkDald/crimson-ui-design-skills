# ULTRA-HARD Index

This directory is the token-unconstrained deep layer. Load only relevant guides, but do not compress their reasoning once selected.

## Foundations

- `foundations/product-brief-reconstruction.md` — Reconstruct the real product brief from code, content, workflows, screenshots, data, and user intent before changing visuals.
- `foundations/design-thesis.md` — Turn product subject, audience, proof, brand tension, and platform constraints into one coherent design thesis.
- `foundations/information-architecture.md` — Design information architecture around user decisions, object relationships, frequency, and recovery paths rather than generic page templates.
- `foundations/task-modeling.md` — Model tasks as goals, preconditions, actions, intermediate states, outcomes, interruptions, and recovery.
- `foundations/state-modeling.md` — Represent UI state explicitly so loading, empty, partial, stale, error, success, disabled, offline, and permission states cannot collapse into ambiguous visuals.
- `foundations/hierarchy-and-attention.md` — Allocate visual attention according to task importance instead of decorative intensity.
- `foundations/composition-multiscale.md` — Compose at page, section, component, control, and micro-alignment scales simultaneously.
- `foundations/grid-systems.md` — Use grids as decision infrastructure for alignment, hierarchy, rhythm, responsive recomposition, and controlled exceptions.
- `foundations/spacing-rhythm.md` — Treat spacing as a semantic relationship system rather than arbitrary margins.
- `foundations/typography-system.md` — Design typography as a hierarchy of roles, measures, line lengths, weights, contrast, optical rhythm, and responsive behavior.
- `foundations/color-system.md` — Build color from semantic roles, value hierarchy, hue relationships, contrast, theme parity, and state meaning.
- `foundations/surface-language.md` — Define when a surface exists, what boundary it communicates, and how elevation/border/radius support semantics.
- `foundations/shape-language.md` — Derive geometry from product/domain character while keeping controls recognizable and hit targets reliable.
- `foundations/iconography-system.md` — Use coherent icon families, custom SVG where domain-specific, and accessible labeling rather than pictographic noise.
- `foundations/imagery-art-direction.md` — Treat imagery, screenshots, 3D, diagrams, illustration, texture, and photography as information/art direction rather than filler.
- `foundations/motion-language.md` — Define motion hierarchy, physics, duration, interruption, reduced-motion behavior, and state communication.
- `foundations/interaction-language.md` — Create predictable hover, pressed, focus, drag, selection, disabled, pending, and success feedback across input methods.
- `foundations/content-hierarchy.md` — Structure copy from user questions and decisions, not internal feature taxonomy.
- `foundations/proof-hierarchy.md` — Match proof type and strength to user risk, skepticism, and decision stage.
- `foundations/product-specificity.md` — Make the interface structurally specific to the product even with logo and accent removed.
- `foundations/design-deliberation.md` — Generate and compare structurally different directions only when ambiguity justifies exploration.
- `foundations/reference-analysis.md` — Extract transferable principles from references without copying their surface style or product-specific assumptions.
- `foundations/anti-template-analysis.md` — Detect bundled AI defaults and generic composition signatures without banning useful patterns individually.
- `foundations/controlled-irregularity.md` — Use asymmetry, overlap, variable density, and exceptions deliberately while preserving comprehension.
- `foundations/consistency-vs-uniformity.md` — Preserve system consistency without making every surface, spacing interval, card, section, and transition identical.
- `foundations/design-token-architecture.md` — Map visual decisions into semantic tokens that can survive themes, states, platforms, and component variants.
- `foundations/design-system-governance.md` — Govern components, tokens, variants, deprecations, adoption, exceptions, and regression checks.
- `foundations/accessibility-as-design.md` — Integrate semantic structure, keyboard, focus, contrast, text scaling, reduced motion, screen readers, and non-color cues from the start.
- `foundations/localization-rtl.md` — Design for text expansion, bidi/RTL, pluralization, locale formats, and mirrored spatial conventions without breaking hierarchy.
- `foundations/ethics-and-trust.md` — Avoid deceptive UI, fabricated proof, dark patterns, misleading urgency, hidden consequences, or fake success.

## Web

- `web/web-page-grammar.md` — Compose websites as narrative systems with orientation, proof, explanation, reset, deeper evidence, and conversion beats rather than independent blocks.
- `web/hero-strategy.md` — Design the first viewport around orientation, subject, proof, and action—not an obligatory giant heading plus gradient orb.
- `web/landing-page-architecture.md` — Match page structure to awareness, skepticism, product complexity, conversion friction, and proof availability.
- `web/marketing-site-craft.md` — Balance expressive brand identity with clear product comprehension, proof, semantics, performance, and conversion.
- `web/portfolio-craft.md` — Make portfolio sites communicate taste and work quality through project sequencing, art direction, case-study depth, and frictionless exploration.
- `web/studio-site-craft.md` — Design studio/agency sites around point of view, work evidence, process credibility, team character, and memorable composition.
- `web/editorial-web.md` — Use editorial hierarchy, reading rhythm, typographic pacing, media sequencing, and navigation for long-form content.
- `web/documentation-web.md` — Prioritize wayfinding, search, code/content hierarchy, version context, progressive examples, and deep-link stability.
- `web/ecommerce-web.md` — Design discovery, evaluation, variant selection, trust, cart, checkout, and post-purchase states with minimal ambiguity.
- `web/saas-web-app.md` — Balance dense repeated-use workflows with clarity, responsiveness, state visibility, shortcuts, and product-specific work surfaces.
- `web/dashboard-web.md` — Design dashboards around decisions and inspection pathways rather than equal card grids and decorative KPIs.
- `web/auth-web.md` — Make sign-in, sign-up, recovery, verification, SSO, MFA, and error handling secure, accessible, and low-friction.
- `web/pricing-web.md` — Present plans, limits, billing periods, eligibility, feature differences, and next steps without deceptive hierarchy.
- `web/case-study-web.md` — Structure case studies around context, problem, constraints, decisions, artifacts, outcomes, and honest attribution.
- `web/interactive-storytelling.md` — Use scroll, sequence, spatial transitions, and media choreography only when they strengthen comprehension and subject experience.
- `web/web-3d-and-canvas.md` — Use WebGL/canvas/3D with explicit input, fallback, performance, accessibility, loading, and device constraints.
- `web/web-motion-choreography.md` — Coordinate page-level, section-level, component-level, and feedback motion with hierarchy and interruption rules.
- `web/responsive-recomposition.md` — Recompose hierarchy, order, crop, density, navigation, and motion for narrow/wide screens instead of merely stacking desktop.
- `web/mobile-web-craft.md` — Design browser/mobile web around thumb reach, viewport changes, safe areas, keyboards, touch, and performance.
- `web/web-performance-craft.md` — Treat loading speed, rendering stability, media budgets, fonts, hydration, and interaction latency as part of perceived design quality.
- `web/web-accessibility-craft.md` — Preserve semantic HTML, headings, landmarks, form labeling, focus, reduced motion, contrast, and screen-reader coherence in expressive designs.
- `web/seo-and-semantics.md` — Align semantic structure, metadata, canonicalization, structured data, headings, links, and crawlability with real content hierarchy.
- `web/web-component-architecture.md` — Keep layout primitives, content components, product components, and stateful interaction components distinct enough for art direction and maintenance.
- `web/web-navigation-systems.md` — Design global, local, utility, contextual, breadcrumb, search, and mobile navigation as one coherent wayfinding system.
- `web/web-footer-strategy.md` — Use the footer as closure, navigation, trust, legal context, secondary conversion, and brand punctuation—not a dump of links.

- `applications/offline-sync-ui.md` — Design local/remote state, sync, conflicts, stale data, queueing, offline edits, and reconnection.
- `applications/permissions-and-privilege-ui.md` — Explain capability needs, request at useful time, represent denied/limited states, and provide recovery without coercion.
- `applications/notifications-and-tray.md` — Design notification, toast, tray, badge, background status, quiet modes, and action behavior without duplicating core state.

## Verification

- `verification/runtime-verification.md` — Prove behavior in the actual runtime rather than inferring success from source code.
- `verification/visual-qa.md` — Inspect hierarchy, composition, alignment, density, typography, surfaces, color, icons, media, motion, and polish in rendered output.
- `verification/interaction-qa.md` — Verify pointer, keyboard, touch, controller, focus, drag, shortcut, and interruption paths separately.
- `verification/state-qa.md` — Exercise empty, loading, success, partial, stale, error, offline, permission, disabled, and recovery states.
- `verification/responsive-qa.md` — Test narrow, medium, wide, ultrawide, zoom/text scaling, orientation, safe areas, and overflow.
- `verification/accessibility-qa-deep.md` — Verify semantics, name/role/state/value, focus order, contrast, text scaling, reduced motion, and assistive technology paths.
- `verification/performance-qa.md` — Measure startup, interaction latency, layout/render cost, memory, media, network, animation, and long-session degradation.
- `verification/visual-regression-qa.md` — Use stable fixtures, state matrices, screenshot baselines, diff tolerances, and deliberate review of expected changes.
- `verification/cross-browser-qa.md` — Test browser engines, viewport behavior, input, fonts, media, layout, and feature fallbacks where web support matters.
- `verification/cross-platform-qa.md` — Test platform conventions, fonts, DPI, windowing, file paths, input, packaging, and native behavior across targets.
- `verification/theme-qa.md` — Verify light/dark/high-contrast/system themes, semantic states, media adaptation, and token parity.
- `verification/localization-qa.md` — Stress text expansion, RTL, CJK, long words, numerals, dates, pluralization, and truncation.
- `verification/content-integrity-qa.md` — Verify claims, labels, links, legal copy, prices, metrics, screenshots, names, and success states against real data.
- `verification/destructive-action-qa.md` — Verify consequence communication, confirmation/undo choice, permission, failure, partial completion, and recovery.
- `verification/data-loss-qa.md` — Test unsaved state, autosave, crash/restart, navigation, close, overwrite, conflict, and recovery.
- `verification/packaging-release-qa.md` — Verify production build, assets, fonts, permissions, updater, signing, install/uninstall, file paths, and first launch.
- `verification/security-ui-qa.md` — Verify permission boundaries, untrusted content, unsafe link/open behavior, credential handling, privilege prompts, and error disclosure.
- `verification/anti-ai-template-qa.md` — Audit generic composition bundles, copy clichés, cardification, fake proof, over-polish, and product interchangeability.
- `verification/human-craft-qa.md` — Audit page rhythm, controlled exceptions, optical balance, art direction, proof sequencing, and memorable subject-specific details.
- `verification/stop-condition-qa.md` — Stop when acceptance is met and further polish would add churn, risk, or generic decoration rather than value.
