# HARD Freeze Policy

Crimson UI Design HARD is a frozen snapshot.

- No `check_for_updates.py`.
- No automatic GitHub Release polling.
- No background update task.
- No automatic synchronization with Standard or Light.
- No personal token or credential is required for normal skill use.
- Future HARD changes require an explicit user request to create a new frozen snapshot.

Tooling may access external developer tools only for a concrete task and according to their trust level; tooling is unrelated to self-updating the skill.
