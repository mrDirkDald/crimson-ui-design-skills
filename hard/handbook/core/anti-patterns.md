# Anti-Patterns

Do not turn these into absolute bans; use them as suspicion triggers.

- card for every group;
- giant hero inside repeated-use app;
- glass/blur as quality substitute;
- neon accent on every action;
- badge/chip spam;
- icon on every label;
- sidebar with no persistent IA need;
- active state that resembles disabled;
- 14 different radii;
- random local hex values;
- placeholder-like logo treatment;
- fake metrics;
- decorative charts with no question;
- infinite gradients;
- animation stack with no thesis;
- mobile = desktop stacked;
- dark theme = color inversion;
- destructive action styled like ordinary secondary action;
- “premium” = more spacing and larger type.
