# Responsive and Adaptive Design

Responsive layout changes with available space. Adaptive design also changes interaction model, density, navigation, and control presentation according to device/input/platform.

## Breakpoint reasoning

Choose breakpoints where composition breaks, not because a framework provides named device widths.

## Reprioritization

On narrow screens, keep the primary job and state visible. Secondary panels can become sheets, accordions, detail routes, or contextual drawers.

## Tables

Options include horizontal scroll, column priority, stacked key/value, drill-down detail, or summary rows. Do not squeeze ten columns into unreadable width.

## Desktop density

Do not mobile-ize desktop tools. Dense data grids, keyboard commands, hover affordances, multi-pane layouts, and persistent inspectors can be appropriate.

## Foldable / split-screen / multi-window

Where platform supports them, avoid fixed full-screen assumptions.
