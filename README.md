# Crimson UI Design Skills

Collection of the five supplied Crimson UI Design skill packages, preserved as separate editions.

| Edition | Directory | Release asset |
| --- | --- | --- |
| Light | `light` | `Light.zip` |
| Standard | `standard` | `Standart.zip` |
| Light with reports | `light-with-reports` | `Light(+rep).zip` |
| Ultra hard | `ultra-hard` | `ultra hard.zip` |
| Max | `max` | `hard.zip` |

Each directory contains the package files in their original layout. The original ZIP packages are attached to the GitHub release.
